// This is the initial draft for the requirement set '1234'.
// Title: Using an 'Automatic Teller System' (ATM)

# General (not yet classified)
The system must be available 24 hours a day.
The system must accept credit cards and debit cards. Permitted credit cards are: VISA, MasterCard, American Express. Permitted debit cards are: GiroCard.
When a user inserts a card, the system must show a message on the screen within 5 seconds.
When a card is not permitted, the system must show a message.
The user must be able to select one of these languages: English, French, German.
The default language is 'English'.
The user must select from these amounts: 10 GBP, 20 GBP, 50 GBP, 100 GBP.
If the user has not enough credit on his card, the system must show a message and must not give out the requested amount.
The system must securely mount to the wall. 

> Does the system allow for future expansion of supported card schemes without core changes?

Future expansion of supported card schemes must not affect core changes.

> What is the expected average response time for all user interactions?

The average response time for 95% of all transactions is 2 seconds.

> Are the specified response times achievable under peak load conditions?
The ATM is a single-user system. So, the specified response times under peak load conditions are achievable.

If the network connection from the ATM to the backend system is not available, the system must show a message to the user. 

After a cash withdrawal, the system must eject the credit card within 5 seconds.

Der Bildschirm muss entspiegelt sein, damit einfallendes Sonnenlicht den Anwender nicht blendet.

> What is the rationale behind the fixed withdrawal amounts, and are there any scenarios where custom amounts or different
denominations might be required or desired by users?

No custom amounts for withdrawal are needed. We only provided fixed amounts. With this we can make sure that we always have the correct bank notes available for the user.
